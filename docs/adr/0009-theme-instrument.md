# ADR 0009：默认主题采用「Instrument（精工仪器感）」

**状态**：已采纳

## 背景
需要一套默认视觉语言：经得起审美挑剔，但不走 Web 式扁平化；与 Windows 原生环境协调，定制克制。

## 决策
- 默认且唯一的内建主题为 **Instrument**，提供浅色与深色两套令牌，并支持系统高对比度模式。
- 视觉语言的核心：
  - **边界清晰**：每个可交互元素都有 1 物理像素的发丝边框；不存在无边界的"幽灵"控件。
  - **克制的体积感**：凸起元素（按钮、滑块手柄、表头）使用 2–4% 亮度差的纵向微渐变，加 1px 顶部内高光与略深的底边；内凹元素（输入框、列表底、进度槽）使用略暗的底色与 1px 顶部内阴影。光源恒定在正上方。
  - **小圆角**：控件 3 lpx，容器与浮层 4 lpx。不使用胶囊形与大圆角。
  - **紧凑密度**：默认控件高度 24 lpx，面向鼠标与键盘，不为触摸放大。
  - **中性色为主**：界面以冷灰中性色构成，强调色只用于选中、焦点、主要动作与进度，取自系统强调色（可被应用覆盖）。
  - **动效极少**：只用于状态过渡的缓冲（≤120ms）与空间关系提示（菜单/提示的出现），不做装饰性动画；系统关闭动画时全部归零。
- 主题以令牌表达（见 09）。控件规范只引用令牌。主题可被应用整体替换令牌值，但控件的结构与绘制方式不随主题改变——不提供任意换肤引擎。
- 明确的禁止项写入 09，用于评审时判定是否滑向 Web 审美。

## 后果
- 外观有辨识度且在专业工具语境下耐看；与 Win11 自带应用不完全一致，但通过系统字体、系统强调色、系统标题栏、原生行为保持协调。
- 微渐变与内高光要求像素级精确绘制，分数缩放（125%/150%）下的发丝线对齐需要专门规范（见 04、09）。
- 只有一个内建主题，降低了维护面；"换肤"需求以替换令牌值满足。

## 被否方案
- **经典 Win32 精修**：原生感强，但斜面过重，易显复古。
- **贴近 Win11 Fluent**：安全但辨识度低，仍带扁平倾向，且 Mica 等材质依赖系统版本。
