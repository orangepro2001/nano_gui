# 验收清单 M1：渲染与文字

本清单由各规范文档的验收条款汇总而成，是里程碑 M1 的**退出条件**：下表全部条款通过，M1 才算完成（见 [14-roadmap.md](../14-roadmap.md)）。
条款的完整内容（前置条件、步骤、预期）以来源文档为准，本表的"摘要"只是定位用的开头片段。

执行记录写在每行的"结果"列：`通过` / `不通过（原因）` / `阻塞（原因）` / `未执行`（13 的 REQ-TEST-026）。`[人工]` 条款另须在表后的"人工项执行记录"中逐项填写六个字段；自动化条款的执行环境登记在"执行环境记录"中。

共 61 条：单元 35、金图 15、回放 4、计量 4、人工 3。
