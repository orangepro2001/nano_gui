# 控件规范模板

每个控件一份文档，文件名为控件的英文短名（`button.md`），域前缀为 `W-<大写短名>`（`REQ-W-BUTTON-001`）。章节顺序与标题固定，某章不适用时写"不适用"并给出一句理由，不得删章。

写作规则：

- 颜色、尺寸、时长**只能**引用 [09-theme.md](../09-theme.md) 的令牌与绘制基元，不得出现字面量。需要新令牌时，先在 09 增补。
- 系统相关参数（双击时间、拖拽阈值、滚轮行数、菜单延迟、光标闪烁、键盘重复）写"读取系统度量"，并引用 [03-platform.md](../03-platform.md) 的对应接口。
- 事件、焦点、捕获的通用机制引用 [08-input-focus.md](../08-input-focus.md)，本文只写该控件特有的部分。
- 布局参数引用 [07-layout.md](../07-layout.md)。
- 每条行为写成可判定的条款。"按 Windows 原生对应控件的行为"不是合格的条款——必须把行为本身写出来；可以在说明性文字里注明参照的原生控件。
- 验收条款遵循 [00-index.md](../00-index.md) 第 4 节；每个控件至少包含：一条状态矩阵金图、一条鼠标回放、一条键盘回放、一条失效计量。

## 12. API 草案

```zig
// 草案：仅签名
pub const XxxOptions = struct {
    key: ?ui.Key = null,          // 所有控件通用，REQ-FRAME-002
    debug_name: ?[]const u8 = null, // 所有控件通用，供回放脚本与节点检视定位（13）
    enabled: bool = true,
    // …
};
pub const XxxResult = struct {
    // 持续性状态
    hovered: bool,
    focused: bool,
    // 激活类结果（触发同帧第二构建遍，REQ-FRAME-030）
    clicked: bool,
};
pub fn xxx(ui: *Ui, src: std.builtin.SourceLocation, label: []const u8, opts: XxxOptions) XxxResult;
```

控件是 `widgets` 模块的自由函数，首参为 `ui: *Ui`，调用形式 `w.xxx(ui, @src(), …)`（REQ-CONV-008）；容器类控件提供 `beginXxx`/`endXxx` 一对自由函数。

注明：哪些字段是激活类结果；传入切片/指针的存活要求；值由谁拥有（应用传指针 vs 框架保留）。
